# AWS Candidates

> Research completed July 2026. Sources: aws.amazon.com, skillbuilder.aws, awseducate.com.

## Why AWS

No AWS certifications were included in the original EBS roadmap HTML. Adding AWS fills a cloud infrastructure gap — all current certs are AI tools, marketing platforms, or cybersecurity vendors. AWS provides the cloud layer that underpins modern AI deployment.

## Recommended AWS Programmes for EBS

### Tier 1 — All Students (Cross-Disciplinary)

| Programme | Cost | Duration | Level | Badge | Notes |
|---|---|---|---|---|---|
| AWS Educate | Free | Self-paced | Beginner | Credly badges | No credit card required; 12 career pathways |
| AWS Skill Builder Free | Free | 1-24 hrs/course | Beginner-Intermediate | Course completion | 600+ courses including AI/ML |
| AWS Cloud Quest (limited) | Free | 6-20 hrs | Beginner | Credly badge | Gamified, fun |

### Tier 2 — AI/Cloud-Focused Students

| Programme | Cost | Duration | Level | Badge | Notes |
|---|---|---|---|---|---|
| AWS AI Practitioner (AIF-C01) | Training free / Exam $100 | 4-8 weeks prep | Beginner | **Official AWS cert + Credly** | Available in Arabic/French/English; **strongest single AWS credential for AI Passport** |
| AWS Cloud Practitioner (CLF-C02) | Training free / Exam $100 | 4-8 weeks prep | Beginner | **Official AWS cert + Credly** | Cloud literacy baseline |
| AWS Emerging Talent Community | Free | Ongoing | Beginner | **Free exam vouchers** | Earn points → claim free AWS cert exams |

### Tier 3 — Deep Dive (Licence Info IA / Master Ing. Financière)

| Programme | Cost | Duration | Level | Badge | Notes |
|---|---|---|---|---|---|
