# Provider Logo Policy

> **Critical**: Public display of provider logos on ebs.tn requires validation. Some providers restrict logo use; others allow it.

## Provider Logo Rules (General Knowledge)

| Provider | Logo Usage Policy | Can EBS Display? | Notes |
|---|---|---|---|
| **Google** | Brand guidelines allow educational partners to use Google Career Certificates badge. Non-partners should not use Google logos without permission. | Conditional | EBS should apply to Google for Education partnership or display only the student-earned badge (not EBS's own branding with Google logo). |
| **IBM** | IBM SkillsBuild badges are student-earned. IBM logos cannot be used on EBS marketing without IBM permission. | Conditional | Display student-earned badges only. Do not use IBM logo in EBS marketing materials without partnership agreement. |
| **Cisco** | Cisco Networking Academy badges are student-earned. Cisco logo use is restricted to authorized academies. | Conditional | If EBS becomes a Cisco Networking Academy, logo use is permitted. Otherwise, display student-earned badges only. |
| **HubSpot** | HubSpot Academy badges are student-earned. HubSpot logo use is generally permissive for educational contexts. | Likely OK for badges | HubSpot is more permissive than most. Badge display is standard. Marketing use of HubSpot brand should still be checked. |
| **Microsoft** | Microsoft Learn badges are student-earned. Microsoft logo use is restricted. | Conditional | Display student-earned badges only. |
| **Semrush** | Semrush certifications are student-earned. Logo use is permissive for badge display. | Likely OK for badges | Semrush certificates are widely displayed by learners. |
| **Harvard** | Harvard certificates are from edX/online. "Harvard" name use in EBS marketing could be misleading. | **Caution** | Do not imply EBS-Harvard partnership. Display "Harvard via edX" or "Harvard Online" to clarify the relationship. |
| **Coursera** | Coursera badges are student-earned. Coursera logo use is restricted. | Display student-earned badges only | No EBS-Coursera partnership implied. |
| **DeepLearning.AI** | DeepLearning.AI certificates are from Coursera. Logo use is permissive for badge display. | Likely OK for badges | Widely displayed by learners. |

## Recommended Approach

1. **For public-facing pages (ebs.tn)**:
   - Display only student-earned badges/certificates (not EBS's own use of provider logos).
   - Use text descriptions: "Google Digital Marketing Certificate" rather than placing the Google logo.
   - For official partner programmes (if EBS becomes Cisco Academy, AWS Academy, etc.), use official partner logos per the partner's brand guidelines.

2. **For Wall of Badges**:
   - Students display their own earned badges — this is standard and generally permitted.
   - EBS should not add its own branding to student-earned badges.

3. **For marketing materials**:
   - Do not use provider logos without partnership agreement.
   - Use phrases like "Students earn certifications from Google, IBM, Cisco, and others."
   - If EBS secures partnerships (AWS Academy, Cisco Networking Academy, IBM SkillsBuild), use official partner logos per brand guidelines.
