# Provider Rules

> Per-provider rules for the EBS AI Passport. See also [[Provider Policies]] and [[Provider Logo Policy]].

## Public Display Rules

1. Use provider logos where possible (per [[Provider Logo Policy]]).
2. Do not make public cards link directly to external providers (future student space only).
3. Use internal details/modals/pages for certification descriptions on ebs.tn.
4. Display student-earned badges, not EBS-branded logos.

## Internal Tracking Requirements

Each certification record must store:

| Field | Required | Purpose |
|---|---|---|
| External URL | Yes | For future student space links and link validation |
| Last validation date | Yes | Quarterly link crawl tracking |
| Badge/certificate format | Yes | What the student receives (Credly badge, PDF cert, etc.) |
| Cost to student | Yes | Free or paid (and amount) |
| Estimated duration | Yes | Student workload planning |
| Tier assignment | Yes | Required / recommended / optional per programme |

## Provider Quality Criteria

A certification is included in the AI Passport only if it meets ALL criteria:

1. **Recognizable brand**: Provider is known in the industry (Google, IBM, Cisco, etc.).
2. **Free or realistically accessible**: No certification costs more than $100; most are free.
3. **Relevant to programme outcomes**: Skills taught align with programme learning objectives.
4. **Provides certificate, badge, or shareable proof**: Student gets something verifiable.
5. **Stable enough for annual curriculum planning**: Provider platform is not likely to disappear within 2 years.

## Provider-Specific Rules

### Forage
- Display company name first, "Simulation Forage" second.
- Example: "Deloitte Data Analytics Simulation (Forage)"
- Not a replacement for certification exams — counts as applied assessment.

### HubSpot Academy
- 21 of 31 links are generic/broken — must fix before student-space launch.
- Valid links go to specific course pages (e.g., `/courses/social-media`).
- HubSpot badges are widely displayed — permissive for badge display.

### Google
- Do not imply EBS-Google partnership without agreement.
- Display as "Google Digital Marketing Certificate" (text, not logo) unless partnership exists.
- FIBAA ECTS framework enables formal credit recognition.

### IBM
- IBM SkillsBuild is free and institutional access is available.
- Do not use IBM logo in EBS marketing without partnership.
- Display student-earned Credly badges only.

### Cisco
- Cisco Networking Academy requires institutional membership.
- Apply for membership before integrating cyber certifications.
- Student certificates can be displayed once membership is active.

### Harvard via edX
- Do not imply EBS-Harvard partnership.
- Display as "Harvard via edX" or "Harvard Online."
- Cost: $50-300 per certificate (unless EBS secures institutional discount).

### AWS
- AI Practitioner (AIF-C01) is the strongest single AWS credential for AI Passport.
- Training is free; exam costs $100 (can be free via Emerging Talent Community).
- Apply for AWS Academy membership for institutional benefits.
