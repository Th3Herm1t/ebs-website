# Mandatory vs Optional

The legacy `required / recommended / optional` model has been simplified to `mandatory / optional` for the first managed implementation. Recommended items can be reintroduced later if operationally needed.

## Why This Matters

The raw roadmap is too large to become a mandatory student workload. The active catalogue is a curated operational set, not the full raw extraction.

## Requirement Definitions

### Mandatory

Must be completed by the target student group.

Criteria:

- High relevance.
- Reasonable workload.
- Strong provider credibility.
- Supports AI Passport outcomes.
- Can be supervised by Abdelkarim/EBS.

### Optional

Available in the catalogue for ambitious students.

Criteria:

- Useful for employability.
- More niche, advanced, or redundant.
- Useful for clubs, challenges, career office, or portfolio differentiation.

## Current Workload Guardrail

- Current managed catalogue mandatory range: 11-14 certifications per programme.
- No programme currently exceeds 14 mandatory certifications.
- Cohort rollout and semester enforcement are intentionally deferred.
