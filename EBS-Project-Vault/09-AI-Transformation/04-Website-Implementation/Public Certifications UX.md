# Public Certifications UX

## Ahmed's Rule

Public certification cards on the website should not link externally.

## UX Principle

The public website sells EBS's academic value. The student space delivers the external links.

## Public Card Should Show

- Certification title.
- Provider logo.
- Level.
- Recommended year.
- Programme relevance.
- Internal CTA or no CTA.
- Simulation note if applicable.

## Public Card Should Not

- Link directly to Google/IBM/Cisco/etc.
- Become a link farm.
- Overpromise mandatory completion.

## Internal Detail Page/Modal Could Show

- Skills learned.
- Why it matters for the programme.
- Estimated duration.
- Badge/certificate type.
- `Disponible pour les étudiants EBS` messaging.
