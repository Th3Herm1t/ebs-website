# Maintenance Process

## Quarterly Review

| Task | Owner | Output |
|---|---|---|
| Batch-crawl managed catalogue URLs | Abdelkarim (Propulsia) | Updated Link Validation Log |
| Fix broken links | Abdelkarim (Propulsia) | Corrected `final-catalogue.ts` |
| Check badge completion metrics | EBS faculty owner | Completion rate report |
| Review student feedback | EBS faculty owner | Feedback summary |
| Update provider policies | Abdelkarim (Propulsia) | Updated Provider Policies file |

## Annual Review

| Task | Owner | Output |
|---|---|---|
| Remove obsolete certifications | Abdelkarim (Propulsia) + Raouf (EBS) | Updated catalogue |
| Add relevant new providers/courses | Abdelkarim (Propulsia) | New certification candidates |
| Confirm mandatory/optional requirements | Raouf (EBS) approves | Updated Programme Mapping |
| Update website data | Abdelkarim (Propulsia) | Updated ebs.tn pages |
| Review public claims and numbers | Raouf (EBS) | Updated marketing materials |
| Review provider partnerships | Raouf (EBS) | Partnership renewals |

## Before Public Claims

| Check | Owner | Why |
|---|---|---|
| Verify provider/logo usage compliance | Abdelkarim (Propulsia) | Legal risk mitigation |
| Verify certification count is accurate | Abdelkarim (Propulsia) | Credibility |
| Avoid overclaiming mandatory workload | Raouf (EBS) | Student expectations |
| Validate all programme-specific claims | EBS faculty owner | Academic accuracy |

## Maintenance Schedule

| Month | Activity |
|---|---|
| January | Annual review: remove obsolete, add new, confirm requirements |
| April | Quarterly: link crawl, metrics, feedback |
| July | Quarterly: link crawl, metrics, feedback |
| October | Quarterly: link crawl, metrics, feedback. Pre-semester planning. |

## Escalation

- Broken links → Abdelkarim fixes within 1 week.
- Provider policy changes → Abdelkarim updates vault, Raouf approves.
- Obsolete certifications → Abdelkarim flags, Raouf approves removal.
- New certification candidates → Abdelkarim proposes, Raouf approves.
