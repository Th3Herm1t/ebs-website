# Academic Integration Model

## Principle

Certifications support academic learning; they do not replace EBS teaching. The AI Passport is a pedagogical framework, not a MOOC aggregator.

## Components

1. **AI Passport Core**: Mandatory certifications that students complete according to their programme path.
2. **Programme-specific AI workflows**: Applied assignments that require using certification skills in real business contexts.
3. **Certification-backed learning milestones**: Each semester has 2-4 certifications that align with module learning outcomes.
4. **Applied portfolio projects**: At least one per year, assessed using the [[Portfolio and Capstone Model]] rubric.
5. **Badge verification**: [[Badge Verification Workflow]] confirms completion.

## Integration Options

| Option | When | Owner | Workload |
|---|---|---|---|
| Embedded in existing modules | During semester | Module faculty | Cert tasks replace or supplement traditional assignments |
| Dedicated workshops | Start of semester | Faculty + external facilitator | 2-3 hour sessions for tool onboarding |
| Career office challenges | Mid-semester | Career office + faculty | Cross-programme AI challenges with employer involvement |
| Semester capstone requirements | End of semester | Programme director | Capstone project must include AI component |
| Optional clubs and bootcamps | Extracurricular | Student clubs + Propulsia | Open to all students, not for credit |

## Integration by Programme Type

### Licence Programmes

- **L1**: AI literacy focus — 2-3 foundational certs (AI Essentials, Prompt Engineering, AI for Beginners).
- **L2**: Tool proficiency — 3-4 applied certs (specific to programme: marketing tools for Marketing, finance tools for Finance, etc.).
- **L3**: Professional readiness — 2-3 advanced certs + portfolio artifact.

### Master Programmes

- **M1**: AI strategy — 3-4 strategy-level certs (AI for Leaders, Digital Transformation, programme-specific).
- **M2**: AI deployment — 2-3 technical certs + capstone artifact integrating multiple certifications.

## Workload Balance

- **Mandatory certs per semester**: 2-4 target load once semester enforcement is approved.
- **Total mandatory per programme**: defined by the managed catalogue; currently no programme exceeds 14 mandatory certifications.
- **Optional certs**: unlimited, encouraged but not tracked for graduation.
- **Portfolio artifact**: 1 per year (not per semester).

## What to Avoid

- Replacing EBS teaching with MOOC watching.
- Certificate-counting as assessment.
- Faculty disengagement (certifications without pedagogical integration).
- Workload overload from assigning too many mandatory certifications in one semester.
- Treating all certifications as equal (a 15-minute quiz ≠ a 20-hour course).
