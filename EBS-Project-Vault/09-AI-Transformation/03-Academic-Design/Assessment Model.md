# Assessment Model

## Assessment Philosophy

Certifications alone are not sufficient evidence of learning. The assessment model combines external certification, internal assignments, portfolio defense, and reflection.

## Assessment Layers

### Layer 1: Certification Completion (external validation)

- Student completes the required certification on the provider platform.
- Student receives badge/certificate from provider (Google, IBM, Cisco, etc.).
- Student submits proof via [[../05-Operations/Badge Verification Workflow]].
- Weight in module grade: 20-30% (at faculty discretion).

### Layer 2: Applied Assignment (internal validation)

- Faculty assigns a task that requires using the skills from the certification.
- Example: After CERT-011 (Prompt Engineering), student submits a prompt library for a specific business scenario.
- Weight in module grade: 30-40%.

### Layer 3: Portfolio Artifact (integrative)

- Student produces one portfolio artifact per year (L1, L2, L3, M1, M2).
- Assessed using the rubric in [[Portfolio and Capstone Model]].
- Weight in module grade: 20-30%.

### Layer 4: Reflection/Defense

- Student writes a 1-page reflection on their AI usage.
- For master students: oral defense of capstone artifact.
- Weight in module grade: 10%.

## What to Avoid

- Grading only by certificate count — this incentivizes gaming.
- Treating all external courses as equal — a 15-minute Google quiz is not equivalent to a Harvard CS50 module.
- Accepting unverifiable screenshots only — use badge verification workflow.
- No faculty involvement — certifications without pedagogical integration are meaningless.

## Integration with EBS Grading

Each module that integrates AI Passport certifications should document:

- Which cert IDs are aligned.
- Which assessment layers apply.
- Weight distribution.
- Pass/fail criteria for certification completion.

## Pre-Student-Space Assessment

Before the student space exists, assessment can be managed via:

- Google Form for badge submission.
- Shared drive for portfolio artifacts.
- Excel/spreadsheet for tracking completion status.
- Faculty manual validation.
