# Portfolio and Capstone Model

## Purpose

Certificates prove completion. Portfolio proves capability. Every student should graduate with at least one AI-assisted portfolio artifact.

## Portfolio Artifacts by Programme

### Licence en Management

- **Artifact**: AI-assisted business process improvement plan.
- **Example**: Analyze a real business process, identify bottlenecks, propose AI-enabled solutions with ROI estimate.
- **AI tools used**: ChatGPT/Claude for analysis, Google AI for productivity, IBM chatbot for customer-facing prototype.
- **Cert alignment**: CERT-022 (chatbot), CERT-012 (AI productivity).

### Licence en Marketing

- **Artifact**: AI-powered marketing campaign with analytics dashboard.
- **Example**: Build a content calendar using AI, create AI-generated assets, set up Semrush tracking, present results.
- **AI tools used**: Google Digital Marketing, Semrush, HubSpot, AI image generators.
- **Cert alignment**: CERT-055 (Digital Marketing), CERT-067 (SEO), CERT-022 (chatbot).

### Licence en Finance

- **Artifact**: Financial forecasting model with AI-assisted analysis.
- **Example**: Build a revenue/expense forecast in Excel, use AI for scenario analysis, document assumptions and risk factors.
- **AI tools used**: Microsoft AI for finance, IBM data tools.
- **Cert alignment**: CERT-080 (AI for finance leaders), CERT-081 (Finance Essentials), CERT-022 (chatbot).

### Licence en Génie Logiciel — Option IA

- **Artifact**: Working AI application, ML model, or AI agent prototype.
- **Example**: Build a prediction model with Python, train it on a dataset, deploy as a simple web app.
- **AI tools used**: Python, IBM Watsonx, Harvard CS50 frameworks, IBM ML libraries.
- **Cert alignment**: CERT-095 (CS50), CERT-104 (Python), CERT-105 (ML basics), CERT-022 (chatbot).

### Licence en Génie Logiciel — Option Cybersécurité

- **Artifact**: Security analysis workflow using AI-assisted threat intelligence.
- **Example**: Set up a basic SOC dashboard, use AI for log analysis, document incident response procedure.
- **AI tools used**: Cisco cyber tools, Fortinet, AI for threat detection.
- **Cert alignment**: CERT-121 (Intro to Cyber), CERT-122 (Cyber Essentials), CERT-022 (chatbot).

### Masters (all)

- **Artifact**: Professional-grade capstone combining domain expertise + AI deployment.
- **Examples**:
  - Marketing: End-to-end AI-powered marketing stack with Google Ads + Analytics + Semrush + n8n automation.
  - CRM: Data pipeline from HubSpot to Power BI with AI-generated insights.
  - Project Management: AI-augmented project plan with risk prediction and resource optimization.
  - Ingénierie Financière: Quantitative model with AI-assisted risk scoring, validated against Forage simulation data.

## Evidence Requirements

Each portfolio artifact must include:

1. **Brief**: Problem statement, approach, AI tools used.
2. **Demo**: Working prototype, screenshots, or live link.
3. **Reflection**: What AI did well, what it struggled with, ethical considerations.
4. **Risk/ethics note**: Data privacy, bias, hallucination management.
5. **Badge links**: Certifications completed that support this work.

## Assessment Rubric

| Criterion | Weight | Description |
|---|---|---|
| Technical execution | 30% | Does the artifact work? Is it functional? |
| AI integration quality | 25% | How effectively is AI used? Not just "I asked ChatGPT." |
| Domain relevance | 20% | Does it solve a real problem in the student's field? |
| Reflection and ethics | 15% | Critical thinking about AI limitations and risks. |
| Presentation | 10% | Can the student explain and defend their work? |
